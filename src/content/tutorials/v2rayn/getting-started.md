v2rayN 是 Windows 平台上广泛使用的开源代理客户端。它本身只是图形界面外壳，不具备代理能力，实际的加密与转发由它调用的 Xray、sing-box 等内核完成。使用流程也很简单：从 GitHub Releases 下载压缩包解压运行，添加订阅分组并更新，选择节点后开启系统代理即可连接，全程无需安装。

## 核心要点

- v2rayN 是**图形外壳**，代理能力来自 Xray、sing-box 等**内核**，排错时要分清两层；
- 只从 **GitHub Releases** 下载官方压缩包，新手优先选**自带内核的完整包**；
- 订阅按**分组**管理，添加后必须**手动更新一次**才会出现节点；
- 系统代理有**三种模式**，日常使用选「自动配置系统代理」;
- 路由规则建议选**绕过大陆**类预设，境内直连、境外走代理。

## v2rayN 和内核是什么关系？

理解这一点对后续排错至关重要。v2rayN 的架构是「外壳 + 内核」：

- **外壳（v2rayN 本体）**：提供窗口界面，负责节点管理、订阅更新、系统代理设置、路由规则配置；
- **内核（Xray、sing-box 等）**：真正建立加密连接、转发流量的引擎，以独立程序的形式放在 v2rayN 的目录里，由外壳按配置调用。

这就像播放器与解码器的关系：界面是播放器，能不能播某种格式取决于解码器。节点用的协议（如 VLESS、VMess、Trojan）能否连接，取决于内核的支持情况——目前对 VLESS 与 Reality 支持最好的是 Xray 内核。各协议的差异可以参考 [VLESS 和 VMess 有什么区别](/protocols/vless-vs-vmess/)。同样地，遇到报错时先分清：界面打不开是外壳问题，节点连不上多半要看内核日志。

## 如何下载并运行 v2rayN？

1. **找到官方仓库**：搜索 v2rayN 时认准 GitHub 上的项目仓库，通过其 Releases 页面下载——网盘、下载站流传的压缩包存在被篡改的风险；
2. **选择压缩包**：Releases 中通常有多个 zip 包，差别在于是否附带内核与运行环境。新手直接选**自带内核的完整包**，避免解压后因缺内核而无法连接；
3. **解压到独立文件夹**：解压到一个普通目录（如 D 盘下新建文件夹），不要直接在压缩软件里运行，也不要放进需要管理员权限的系统目录；
4. **运行主程序**：双击 v2rayN.exe 启动。首次运行如被 SmartScreen 或杀毒软件提示，属于此类工具的常见误报，确认来源是官方 Releases 后放行即可；
5. **找到主界面**：程序启动后会缩到**系统托盘**，双击托盘图标打开主界面——很多新手以为“没启动成功”，其实它在右下角。

## 如何添加订阅分组并更新？

v2rayN 用「订阅分组」管理机场订阅，一个机场对应一个分组，操作如下：

1. 从机场用户中心复制订阅链接（还没有订阅可先阅读[新手怎么选机场](/airport/beginners/)）；
2. 打开 v2rayN 的**订阅分组设置**，新建分组：备注填机场名称，地址栏粘贴订阅链接，保存；
3. 回到主界面，执行**更新订阅**操作；
4. 更新成功后，节点列表中会出现该分组下的全部节点；
5. 选中节点执行**真连接延迟测试**，挑一个延迟正常的节点，将其**设为活动服务器**；
6. 此后定期更新订阅，机场更换服务器后旧节点会整体失效。

如果更新订阅失败，先核对链接完整性，再在「通过代理更新」与「不通过代理更新」之间切换尝试；如果节点列表正常但测试全部超时，按[节点全部超时怎么办](/troubleshooting/all-nodes-timeout/)的顺序排查。对节点与订阅概念还不熟悉的读者，可以先读[什么是代理节点](/nodes/what-is-a-proxy-node/)。

## 系统代理的三种模式有什么区别？

选好节点后，还需要让系统流量进入 v2rayN 的本地端口，这由**系统代理模式**控制：

| 模式 | 行为 | 适用场景 |
| --- | --- | --- |
| 清除系统代理 | 不设置系统代理，流量不自动进入客户端 | 停用代理，或仅供个别程序手动指定端口 |
| 自动配置系统代理 | 修改 Windows 代理设置，指向本机监听端口 | 日常使用的推荐选择 |
| 不改变系统代理 | 保持系统现有设置不动 | 代理设置已由其他工具管理时 |

日常使用选「自动配置系统代理」即可。需要注意，系统代理只对遵守该设置的程序（浏览器、多数联网应用）生效，命令行工具、游戏等可能绕过它；如需在网络层接管全部流量，可再研究 v2rayN 的 TUN 模式，思路与 [Clash 的 TUN 模式](/tutorials/clash/getting-started/)一致。

## 路由规则应该怎么设置？

路由规则决定哪些流量走代理、哪些直连。v2rayN 内置了几套预设，含义如下：

- **绕过大陆**：境内域名与 IP 直连，其余走代理——日常推荐，兼顾速度与流量消耗；
- **全局代理**：所有流量都走节点，排查“规则没匹配”类问题时临时使用；
- **全局直连**：所有流量不走代理，等于暂时停用。

新手保持「绕过大陆」即可，不必急于编写自定义规则。如果发现某个国内网站被错误地走了代理（或相反），再学习为单个域名添加例外规则也不迟。

## 常见报错应该往哪个方向排查？

- **节点全部超时**：优先怀疑订阅过期、机场换服务器或账户流量用尽，先更新订阅再测；
- **启动或连接时报端口占用**：本机同时运行了 Clash 等其他代理软件，两者监听端口冲突——同一时间只开一个客户端；
- **启动报缺少运行环境**：换用附带运行环境的完整包，或按提示安装对应组件后重试；
- **浏览器不走代理**：检查系统代理模式、浏览器代理插件是否抢占设置；
- **个别协议节点无法使用**：多为内核版本过旧，不支持该协议，升级客户端与内核。

## 总结

v2rayN 的上手路径可以概括为一条直线：官方 Releases 下载完整包 → 解压运行 → 新建订阅分组并更新 → 测延迟选节点 → 系统代理选「自动配置」→ 路由选「绕过大陆」。理解「外壳 + 内核」的架构后，大多数报错都能快速归类到订阅、内核或端口冲突三个方向。作为 Windows 上的轻量方案，它与 Clash 系客户端各有所长，掌握其一后再上手另一个也毫无压力。
