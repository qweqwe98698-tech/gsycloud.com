GSY Cloud 官方网站今日正式上线。本站的定位是四位一体：GSY Cloud 的品牌官网、机场选择的参考手册、系统化的网络知识库，以及客户端教程与故障排查中心。我们希望用一套结构清晰、立场透明的内容，帮助中文用户更省心地理解和使用网络工具。

## 已上线哪些栏目？

首批上线的栏目覆盖从服务到知识的完整链路：

- [服务介绍](/services/)：GSY Cloud 自身服务与套餐的官方说明；
- [机场指南](/airport/)：选择方法与场景化建议，新用户可从[新手选机场指南](/airport/beginners/)读起；
- [节点知识](/nodes/)：代理节点的基础概念与使用常识；
- [客户端教程](/tutorials/)：主流客户端的入门配置教程，例如 [Clash 快速上手](/tutorials/clash/getting-started/)；
- [故障排查](/troubleshooting/)：按症状组织的排查手册，帮你快速定位问题；
- [线路知识](/network/)：IPLC、IEPL、原生 IP 等线路概念解析；
- [协议知识](/protocols/)：常见代理协议的原理与对比；
- [AI 网络](/ai/)：ChatGPT、Claude 等 AI 工具的网络环境专题；
- [流媒体](/streaming/)：Netflix 等平台的地区判定与解锁知识；
- [风险预警](/risk/)：机场行业的风险识别与止损方法；
- [官方动态](/news/)：GSY Cloud 的公告与更新说明。

## 我们坚持什么内容原则？

- **官方与编辑内容分离**：官方公告、服务说明与编辑团队的知识内容分别标注，立场一目了然；
- **数据状态透明**：不虚构测速数据与评测结论，参考性解读均明确标注数据状态；
- **不做伪装评测**：GSY Cloud 的自身服务只以品牌身份出现，不伪装成第三方推荐。

完整标准见[编辑政策](/editorial-policy/)，关于团队的更多信息见[关于我们](/about/)。

## 后续会有哪些内容？

接下来我们将扩充更多客户端的教程专题，延伸 AI 工具网络环境系列的覆盖范围，并根据行业变化持续修订故障排查与风险预警内容。新增与重要修订都会通过官方动态栏目发布。

## 总结

GSY Cloud 网站的目标，是把服务介绍、选择参考、网络知识与故障排查整合进同一个体系，并用透明的内容原则赢得信任。网站会随行业变化持续演进，欢迎从任一栏目开始探索，也欢迎通过站内渠道向我们反馈建议。
